# Flicker EEG Attention - Healthy Adults Manuscript

This repository contains analysis code for the Flicker EEG Attention study in healthy adults.

## Repository Structure

- **Behavior Analysis** - Python code for behavioral data analysis
- **EEG Analysis** - MATLAB code for EEG data processing and analysis

Each folder contains its own README with detailed instructions for running the corresponding analyses.

## Getting Started

Navigate to the relevant analysis folder and consult the README for setup instructions and usage guidelines.
